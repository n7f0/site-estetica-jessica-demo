# Jéssica Estética — prévia visual

Este repositório contém uma demonstração estática e pública do design do site.

- Não contém banco de dados, API, credenciais ou painel administrativo.
- Os serviços, textos e elementos gráficos são ilustrativos.
- Os botões de agendamento exibem um aviso: não enviam dados nem criam reservas.
- O site oficial e o repositório principal permanecem separados.

## Publicação no GitHub Pages

Em **Settings → Pages**, selecione **Deploy from a branch**, escolha a branch **main** e a pasta **/(root)**. Salve e aguarde a publicação.

Endereço esperado: https://n7f0.github.io/site-estetica-jessica-demo./
